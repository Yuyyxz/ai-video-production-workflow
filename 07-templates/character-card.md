# 📋 角色卡模板 (Character Card Template) — 长视频生产版

> **用途**: 为文生图/图生视频提供角色一致性描述
> **核心规则**: 外观描述必须逐字符复制到所有 Image 2 prompt 中
> **增强版**: 加入三视图/表情包/参考图集引用(供 AIYOU 式一致性方案)

---

## 角色卡

```yaml
# ============ 基本 ============
角色名: ""                      # 中文名
英文名: ""                      # 用于英文 prompt
年龄: 
性别: 
身份/职业: ""                   # 故事中的身份

# ============ 外观描述 (English, 逐字复制!!) ============
appearance: >
  (英文描述: 发型/眼睛/肤色/脸型/体型/身高, 必须精确到细节)

# ============ 服装 ============
outfit_default: >
  (日常服装, 英文)
outfit_01: >
  (场景1服装, 英文)
outfit_02: >
  (场景2服装, 英文)

# ============ 参考图集 (一致性关键) ============
ref_images:
  - "CHR-01_V01_front.png"      # 正面
  - "CHR-01_V01_side.png"       # 侧面
  - "CHR-01_V01_three_quarter.png"  # 3/4侧
  - "CHR-01_V01_expression.png" # 表情参考(可选)
  - "CHR-01_V01_outfit.png"     # 服装参考(可选)

# ============ 性格 (参考, 不用于 prompt) ============
personality: ""

# ============ 音色 (用于配音/TTS) ============
voice: >
  (音色描述: 年龄段/声线/语速/口癖/情绪特征)

# ============ 台词风格 ============
speech_style: >
  (句式习惯/口头禅/礼貌程度)

# ============ 人物弧光 ============
arc: >
  (起点: 什么状态 → 终点: 变成什么样)
```

---

## 一致性规则

| 规则 | 说明 |
|------|------|
| **逐字复制** | `appearance` 字段必须完全一致地出现在每个 prompt 中 |
| **禁止改写** | 不可将 "black hair" 改为 "dark hair" |
| **位置固定** | 角色描述在 prompt 开头, 场景描述在后 |
| **多人场景** | 按出场顺序依次插入各角色的 appearance |
| **参考图锚定** | 图生视频时用参考图 + 角色卡双保险 |
| **改卡必同步** | 修改角色卡后, 所有已生成 prompt 需同步 |

## 使用示例

```
[appearance逐字复制 + outfit_default逐字复制] + 场景 + 构图 + 光线 + 风格
```

## 文件命名

```
CHR-{编号}_V{版本}_{描述}.md / .png
CHR-01_V01_front.png
CHR-01_V02_three_quarter.png
```
