# 人物设定卡 —《我真没想重生啊》真人剧改编

> 提取自小说原文(柳岸花又明《我真没想重生啊》)
> 用途: 选角参考 + 角色一致性锚定 + 画风/服装/场景设计
> 画风定位: 高清电影质感 + 新海诚式光影 + 2000年代中国环境细节 + 四季

---

## 角色一: 陈汉升(男主)

### 基本信息
- 身份: 35岁社会精英重生回高三毕业生(心理35, 身体18)
- 前世: 钻石单身汉, 创业成功, 社会地位高, 精力阅历能力巅峰
- 今世: 港城一中高三毕业生, 刚经历高考后向萧容鱼表白被拒

### 外貌(重生后 = 18岁身体)
- 从小说看外貌描写较少, 需设定: 少年身材, 但眼神有与年龄不符的成熟沉稳
- 关键特质: **"身体18岁, 眼神35岁"** —— 这是全剧最大的视觉反差点

### 性格气质
- 前世: 收放自如、谈吐不俗、城府深、韧性极强(屡败屡战终成功)、交往能力强
- 重生后: 用成年人的成熟和阅历, 重新审视青春里的每个人、每个选择
- 核心矛盾: 知道未来走向, 却要重新做那些改变命运的抉择

### 人物弧光
- 起点: 成功但空虚的35岁精英, 应酬后只有疲惫和不知所措
- 转折: 重生, 有机会弥补前世遗憾
- 终点: 在沈幼楚(宝藏女孩)和萧容鱼(白月光)之间, 重新定义"什么才是真正重要的"

### 关键戏份
- 重生醒来的错愕(35岁灵魂住进18岁身体)
- 用成年阅历重新看同学、老师、家人
- 面对两个女孩的抉择(全剧情感核心)

### 视觉关键词(用于生成)
- 少年外貌 + 沉静成熟眼神 / 港城一中校服 / 2000年代学生装扮
- 高中→大学跨度, 需要两个年龄段的形象

## 角色二: 沈幼楚(宝藏女孩)

### 基本信息
- 身份: 港城一中女生, 后升大学
- 家庭: **父母双亡**, 申请助学贷款, 性格自卑, 不太合群

### 外貌(小说原文)
- **1米7 高挑身材**(常藏在宽松旧校服里)
- 肌肤**瓷白嫩滑**, 长发**自然微卷**
- 脸蛋**娇艳如桃花**, 迷茫又害羞
- 穿不合身的及膝雪纺裙时, "几乎让每个男人都激起保护欲"
- 声音**小的像蚊子**, 不敢平视, 低头看地面

### 性格气质
- 自卑、害羞、善良、温柔、坚强(勤工俭学)、不善表达
- 家庭惨但坚韧——图书馆、食堂都有她勤工俭学的身影
- 吃三毛钱米饭和免费汤, 穿旧校服, 却悄悄美得惊人

### 人物弧光
- 起点: 躲在军训帽下、被自卑包裹的宝藏女孩
- 转折: 陈汉升的温柔(剥虾仁、关心)让她第一次被看见
- 终点: (需从后续章节补全) 从自卑走向被珍视

### 视觉关键词(用于生成)
- 高挑纤细 / 瓷白皮肤 / 自然微卷长发 / 桃花般娇艳却害羞的脸
- 旧校服 / 宽大衣服遮住身材 / 低头、躲闪的眼神
- 反差: 明明很美, 却因自卑把自己藏起来

## 角色三: 萧容鱼(白月光)

### 基本信息
- 身份: 港城一中女生
- 设定: **港城一中建校几十年以来最漂亮的女学生**

### 外貌(小说原文)
- 白皙的手背, 优美浑圆的小腿(又白又嫩)
- 清冷女神气质, "白月光"定位
- 具体五官描写较少, 需按"校花女神"设定补全

### 性格气质
- 清醒、有原则、理性
- 拒绝表白的理由一以贯之: 初中不谈恋爱→高中不谈恋爱→大学毕业前不谈恋爱
- 不是高冷傲慢, 是**有自己清晰的节奏和边界**

### 人物弧光
- 起点: 陈汉升的白月光, 高考后表白被拒
- 特点: 她是"过去的执念", 代表陈汉升前世没能得到的遗憾
- 终点: (需补全) 白月光与宝藏女孩的抉择, 是全剧的情感张力核心

### 视觉关键词(用于生成)
- 校花级外貌 / 白皙 / 清冷气质 / 有边界感不轻浮
- 2000年代女学生装扮(校服/清新)
- 与沈幼楚形成对比: 一个光芒外露, 一个藏美于内

---

## 三主角关系张力(全剧核心)

```
陈汉升(重生者)
   ├── 沈幼楚 = 宝藏女孩 = 今生该珍惜的(温柔、被忽视、值得守护)
   └── 萧容鱼 = 白月光 = 前世没得到的执念(清冷、理性、求而不得)
```

- 核心冲突: 重生的意义, 不是"选谁", 而是"重新看清什么是真正重要的"
- 情感基调: 遗憾催泪 + 温柔心疼 + 青春白月光

---

## 待补全(需要你决定或继续读小说)

1. 萧容鱼的五官细节(小说里偏少, 选角时需补全)
2. 沈幼楚的结局弧光(从自卑到被珍视的完整路径)
3. 陈汉升最终选择(或开放式结局)
4. 三个角色的年龄跨度: 高中(18岁) vs 大学 vs 是否拍到重生前的35岁
