## 配音规范

- 每角色同一音色ID贯穿全片
- 情绪变化通过语气调节, 不换音色
- 语气标注写进台词稿: (低声) (慌张) (温柔)

## 台词稿格式

```
[场景 SB-012] [角色 CHR-01] [语气 低声害羞]
「……何を見てるの？」

[场景 SB-013] [角色 CHR-02] [语气 慌张结巴]
「い、いや……何でもない……」
```

## 台词稿 → 配音流程

1. 从 dialogue-table.md 导出台词稿
2. 按角色分组生成音频
3. 每句生成后登记: AU-V01-001.mp3
4. 情绪段落在配音后人工抽听
