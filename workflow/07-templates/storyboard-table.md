# 分镜表模板 (Storyboard Table)

> 每行一个镜头。P3 分镜阶段的核心产出。
> 一个镜头 = 一个节拍 = 一个变化。

## 分镜表

| 镜头号 | 场景 | 景别 | 角度 | 镜头运动 | 时长(s) | 画面内容 | 台词 | 声音/音效 | 首帧来源 | 状态 |
|--------|------|------|------|---------|---------|---------|------|-----------|---------|------|
| SB-001 | 教室 | 中景 | 平视 | 锁定 | 5 | 林檎坐在窗边看书 | — | 翻书声, 蝉鸣 | storyboard | ☐ |
| SB-002 | 教室 | 近景 | 平视 | 缓推 | 5 | 蓮在门口偷看 | 「……何を見てるの？」 | 心跳声 | tail_frame | ☐ |

## 字段说明

| 字段 | 说明 |
|------|------|
| 镜头号 | SB-XXX 唯一编号 |
| 景别 | 极远景/远景/中景/近景/特写 |
| 角度 | 平视/俯视/仰视/斜角 |
| 镜头运动 | 锁定/推/拉/跟/摇/环绕/手持 |
| 时长 | 5s 为一段生成单位, 可多段组合 |
| 画面内容 | 主体+动作+环境, 物理描述 |
| 台词 | 本镜头内的对白 |
| 声音/音效 | 环境音/音效/BGM 提示 |
| 首帧来源 | storyboard(用分镜图) / tail_frame(接上段尾帧) |
| 状态 | draft/approved/done/failed |

## 首帧来源决策规则

- 同空间 + 同时间线 + 无跳切 → `tail_frame`
- 换空间/换时间/换角色/闪回 → `storyboard`
- 不确定 → `storyboard`(保守)

## 镜头节奏参考

| 场景类型 | 平均镜头时长 |
|---------|-------------|
| 对话 | 3-5s |
| 动作 | 2-4s |
| 氛围/空镜 | 5-8s |
| 高潮 | 2-3s |

## 导演五问(每镜头写prompt前回答)

1. 功能: 这场戏在故事里干什么?
2. 转折: 价值翻转是什么?
3. 视角: 我们在谁的体验里?
4. 权力: 谁拥有权力, 如何移动?
5. 潜台词: 什么是真的但没说出来?
